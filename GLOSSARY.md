# Kubernetes Tamil Glossary / குபெர்னெட்டீஸ் தமிழ் சொற்களஞ்சியம்

This glossary provides consistent Tamil translations for Kubernetes technical terms used across all translated documentation pages.

இந்த சொற்களஞ்சியம் அனைத்து மொழிபெயர்க்கப்பட்ட ஆவணப் பக்கங்களிலும் பயன்படுத்தப்படும் Kubernetes தொழில்நுட்ப சொற்களுக்கான நிலையான தமிழ் மொழிபெயர்ப்புகளை வழங்குகிறது.

## Usage Rules / பயன்பாட்டு விதிகள்

1. On **first use** in a page, write the English term followed by Tamil in parentheses: `Pod (பாட்)`
2. After first use, use the English term inline in Tamil sentences
3. Terms marked "Keep as-is" should **never** be translated — use the English term directly
4. Code blocks, CLI commands, and API fields always remain in English
